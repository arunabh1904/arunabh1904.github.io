# Python Interview Trivia

This 88-card deck reviews Python through work that recurs in ML engineering. The scenarios cover configuration boundaries, dataset plumbing, preprocessing, evaluation, and inference services. Each card keeps the code or design scenario with the concept it tests. Enter the short canonical answer, then use the reveal to check the rule and its production consequence.

The scope is Python 3.11+ and Pydantic v2. Tensor operations, autograd, device placement, distributed training, and `DataLoader` behavior stay in the separate PyTorch deck.

## How to use the deck

Choose one engineering topic for a focused pass or keep all topics mixed. Enter the short answer, then select **Grade answer**. Exact answers and listed aliases score **Correct**; partial terms or a one-character typo score **Close**; other responses score **Needs work**. The score updates automatically and follows the selected topic.

Most prompts ask you to predict code, diagnose a bug, or choose an interface. Read any snippet before answering and recall the smallest phrase that identifies the behavior or decision. The explanation then connects that phrase to the underlying Python model.

Grading and progress storage stay in this browser. The core deck excludes lower-frequency internals such as descriptors, metaclasses, advanced generator methods, exception groups, `ContextVar`, and detailed GIL behavior.
