# Python Interview Trivia

This deck uses short recall to build a deep Python revision path. Each card asks for one term, operator, output, or decision in one or two words. The reveal then explains the full rule, its boundary case, and the production consequence.

## How to use the deck

Choose one topic for a focused pass or keep all topics mixed. Enter the one- or two-word answer, then select **Grade answer**. Exact answers score **Correct**; partial terms or a one-character typo score **Close**; other responses score **Needs work**. The score updates automatically and follows the selected topic.

Code scenarios are separate cards marked **Code**. Read the snippet before answering, predict its output or contract, and use the reveal to connect that behavior to the underlying Python model. This second pass is where a memorized term becomes a production decision.

Grading and progress storage stay in this browser. The deck covers semantics, iteration, scope, collections, the object model, resource handling, structured concurrency, runtime typing, dataclasses, and Pydantic.
