# Python Interview Trivia

This 230-card deck reviews the practical Python core through work that recurs in ML engineering and production services. It starts with references, syntax, collections, functions, and object-oriented design. It then moves through typing, dataclasses, Pydantic v2, concurrency, performance, imports, testing, serialization, and failure handling. Each card isolates one decision or gotcha. Enter the short canonical answer, then use the reveal to check the immediate rule and the deeper mental model.

The scope is Python 3.11+ and Pydantic v2. Tensor operations, autograd, device placement, distributed training, and `DataLoader` behavior stay in the separate PyTorch deck.

## How to use the deck

Choose one engineering topic for a focused pass or keep all topics mixed. Enter the short answer, then select **Grade answer**. Exact answers and listed aliases score **Correct**; partial terms or a one-character typo score **Close**; other responses score **Needs work**. The score updates automatically and follows the selected topic.

Most prompts ask you to predict code, diagnose a bug, compare costs, or choose an interface. Read any snippet before answering and recall the smallest phrase that identifies the behavior or decision. **Why it works** resolves the scenario; **Mental model** explains ownership, complexity, lifetime, trust, or concurrency so the rule transfers to unfamiliar code.

Grading and progress storage stay in this browser. “Comprehensive” here means the practical interview and production Python core, not every standard-library module or CPython implementation detail. PyTorch tensor semantics, autograd, modules, distributed training, and data loading remain in the separate PyTorch deck.
