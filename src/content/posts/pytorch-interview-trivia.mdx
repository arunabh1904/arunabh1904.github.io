# PyTorch Interview Trivia

This deck uses short recall to build a deep PyTorch revision path. Each card asks for one API, dtype, shape, state boundary, or system behavior in one or two words. The reveal then explains the tensor or runtime contract that makes the answer true.

## How to use the deck

Start with **Tensors**, **Autograd**, and **Training**. Add modules, data loading, distributed execution, and performance once the single-device path is automatic. The deck includes checkpoint safety, activation recomputation, distributed accumulation, and inference state because those details separate a toy loop from a production system.

Enter the one- or two-word answer, then select **Grade answer**. Exact answers score **Correct**; partial terms or a one-character typo score **Close**; other responses score **Needs work**. The score updates automatically for the selected topic.

Code scenarios are separate cards marked **Code**. Track shapes, devices, dtypes, aliasing, graph state, and synchronization before answering. The reveal explains the production consequence. Grading and progress storage stay in this browser, which keeps short mobile sessions private and available offline after the page loads.
